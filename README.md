📌 About The Project

This project is a frontend implementation of the "Kasper" website design (Template Two) from Elzero Web School[cite: 1].
The main goal of this project was to practice:
* Semantic HTML structure[cite: 1]
* CSS styling and layouts[cite: 1]
* Flexbox[cite: 1]
* Responsive design[cite: 1]
* Working with images, background videos, and fonts[cite: 1]
* Creating reusable UI sections such as Services, Portfolio, Pricing, and Contact forms[cite: 1]
